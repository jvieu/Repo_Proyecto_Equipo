# Base oficial

Esta carpeta contiene las bases originales descargadas desde Spotify Charts y la base homologada final utilizada como punto de partida para la visualización individual.

Las bases originales corresponden a rankings semanales de Spotify Charts de Argentina, Chile, Colombia y México. También se incluye la base homologada completa, **charts_latam_carol.csv**, que reúne los datos limpios y estructurados utilizados posteriormente para construir la base procesada de la visualización.
